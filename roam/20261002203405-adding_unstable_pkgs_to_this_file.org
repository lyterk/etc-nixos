=pkgs-unstable= is already threaded through via =specialArgs=. You just need to use it in =shared/default.nix=.

#+begin_src diff
--- a/etc/nixos/shared/default.nix
+++ b/etc/nixos/shared/default.nix
@@ -3,6 +3,7 @@
 {
   config,
   lib,
   pkgs,
+  pkgs-unstable,
   flakeInputs,
   ...
 }:
@@ -95,7 +96,7 @@
       # editors
       neovim
-      emacs30
+      pkgs-unstable.emacs31
       # shells
       fish
#+end_src

That's it. =pkgs-unstable= is passed as a =specialArgs= in your flake, so any module in the tree can accept it as an argument and reference packages from it with =pkgs-unstable.<package>=.
